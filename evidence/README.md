## 5. Evidence Verification

Before adding any screenshot to this repository, the following aspects should be checked:

- The contribution was actually published in the official course forum.
- Its content corresponds to the academic activity and the descriptive analysis performed.
- The figure number matches the academic report.
- The screenshot is readable and accurately represents the original communication.
- Any private information unrelated to the academic evidence has been excluded.
- Feedback and methodological changes are attributed to the tutor only when supported by the actual communication.
