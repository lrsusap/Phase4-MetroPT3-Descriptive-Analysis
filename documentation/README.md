# Technical Documentation

## MetroPT3 – Phase 4 Descriptive Analysis

This directory contains the supporting technical documentation for the Data Analytics Phase 4 project at Universidad Nacional Abierta y a Distancia (UNAD).

### 1. Academic Technical Report

**File:** `Phase4_Technical_Report.pdf`

The technical report presents the project objectives, dataset characterization, data preparation procedures, descriptive statistical analysis, operating-state comparisons, interpretation of findings, methodological limitations, conclusions, and academic references.

### 2. Technical Code Annex

**File:** `MetroPT3_Technical_Code_Annex.pdf`

The technical code annex provides a reference to the Python instructions and analytical procedures used during the development of the project.

It complements the executable Jupyter notebook and supports the review of the computational methodology.

### 3. Executable Notebook

The executable notebook is located in:

`../notebooks/Phase4_MetroPT3_Descriptive_Analysis_Final.ipynb`

The notebook is the primary resource for reviewing the actual code, execution results, analytical tables, and visualizations.

### 4. Reproducibility

To reproduce the analysis, users must obtain the appropriate MetroPT3 CSV dataset, configure the data access path, install the required libraries, and execute the notebook cells in sequence.

The results correspond to the supplied CSV version containing 1,516,948 records.

### 5. Documentation Status

The report and annex will be added to this directory after their final review and conversion to PDF.

Only verified files and results will be presented as completed academic evidence.
